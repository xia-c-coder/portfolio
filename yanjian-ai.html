一、项目简介与产品定位

1.1 产品名称

言简 AI —— 面向会议密集型团队的智能会议纪要助手（「言简」取自「言简意赅」，寓意把一场 60 分钟的会议，压缩成 3 分钟就能读完、并且能直接执行的结论）。

一句话定义：把「会后整理纪要」这件隐性成本极高的事，从人工劳动变成系统自动产出，而且产出的是可验证、可追踪的结论，而不只是一份逐字稿。

1.2 目标用户

按「会议密度」与「协作半径」两个维度，把目标用户划分为三类人群；占比来自 12 位受访者的人群构成（模拟样本）。

  • 会议密集的产品 / 项目负责人（核心人群，约 50%）：每周 8 场以上会议，会后必须产出纪要并盯决议落地——既要「记得全」，也要「跟得住」，是纪要工具的核心使用者。
  • 跨部门信息对齐者（约 30%）：经常缺席会议或只参加部分场次，依赖纪要补齐上下文——最怕的不是纪要出得晚，而是纪要与事实不一致。
  • 跨国 / 远程协作团队（约 20%）：多语种、多时区协作，纪要需要跨语言直接可用——对翻译有需求，但更在意「跨语言之后结论是否仍然准确」。

1.3 核心定位

区别于市面上「录音 → 转文字 → 人工整理」的传统方案，言简 AI 以「会议结束即产出可验证、可追踪的结论」为唯一入口，覆盖 录音接入 → 高精度转写 → 说话人分离 → 决议提取 → 任务分发与追踪 的会议全闭环，把会后整理纪要的隐性成本降到接近零。

定位取舍 不做「什么都能记」的通用记录器，而是做「结论准确 + 任务可追」的决策助手。这意味着在产品上主动放弃一部分能力（例如会议情绪分析、实时同传），把资源集中在「转写可信」与「决议落地」两件事上——这一取舍由后文的 Kano 数据支撑，而非主观判断。

1.4 核心差异化壁垒

  • 功能壁垒：把价值前置到「决议提取 + 任务分发」，覆盖传统转写工具触达不到的「会开到落地」环节——竞品普遍停在「产出一份纪要」，言简 AI 的交付物是「一条被认领的任务」。（对应 R2 / R3）
  • 数据壁垒：用户对转写的修正、对决议的采纳与驳回，会沉淀为团队专属的领域词库（人名、项目代号、专有名词），反哺识别精度与个性化推荐——用得越久，错得越少。（对应 R1 / R4）
  • 体验壁垒：单场会议 3 分钟内产出结构化纪要，每条结论可一键回溯到原始录音位置，把工具从「记录器」升级为「团队协作的记忆中枢」。（对应 R1 / R2）
  • 商业壁垒：按会议时长与席位分层付费——免费基础版（转写 + 纪要）／团队全功能（决议追踪 + 协作工具打通）／企业私有化（本地部署 + 定制词库）。

计算公式 Better = (A + O) / (A + O + M + I)　—— 功能满足时满意度上升的幅度，取值 0–1，越接近 1 越值得做。
Worse = − (O + M) / (A + O + M + I)　—— 功能缺失时满意度下降的幅度，取绝对值后越接近 1 越不能缺。

2.6 用复合分排出优先级（并带上四象限）

只按 Kano 属性排序会丢掉「程度」信息（同为期望属性，R2 与 R3 的价值并不相同），只按系数排序又会把「不做就流失」的必备属性排在后面。因此这里用属性权重与系数的复合分排序：

优先级计算公式 优先级得分 = 0.5 × 属性权重 + 0.3 × Better + 0.2 × |Worse|
属性权重：必备 M = 1.0、期望 O = 0.8、魅力 A = 0.5、无差异 I = 0.1。权重占 50%，保证「不做就流失」的必备属性不被低 Better 拉低；两项系数合计占 50%，保证满意度杠杆大的期望属性排在前面。
分级阈值：P0 ≥ 0.70，P1 = 0.50–0.69，P2 < 0.50。

5.3 HMW-1｜让「不敢信的转写」变成「可验证的结论」

HMW-1 优化对象：R1 实时转写与说话人分离（必备属性短板） 必备 M|Worse| 0.83P0

问题陈述（POV）

用户：需要在会后 24 小时内回溯会议结论的项目负责人。

需求：在不完整信任转写文本的前提下，快速拿到并验证可执行的会议结论。

洞察：转写准确率是有天花板的——即使达到 97%，错词也会集中落在人名、数字和专业术语上，而这些恰恰是结论里最不能错的词[6]。用户真正的问题不是「转写不够准」，而是「无法验证哪一句可以信」，于是只能退回重听录音，会议纪要因此失去效率价值。

收敛结论：优先做 H1 + H2，并把 H3 并入 H1 的交互入口。理由有三：H2 用最低成本直接降低「关键错词率」（人名、术语是错词高发区），H1 与 H3 用同一个「点击跳原声」的交互同时解决「不敢信」与「找不到」，三者共同把「验证成本」从「重听整场会」压到「点一下就确认」。

  • 纪要中结论可溯源覆盖率 ≥ 90%（每条结论都带可点击的时间戳）。
  • 人名 / 专业术语错词率下降 ≥ 50%（对比未开启热词注入的会议）。
  • 会后「重新听录音」的行为占比下降 ≥ 40%。
  • 纪要人工修改率下降（人工编辑字数 / 纪要总字数）。

HMW-2 优化对象：R2 结构化纪要 + R3 待办流转（期望属性，共享同一断点） 期望 O|Worse| 0.75 / 0.58P0

问题陈述（POV）

用户：需要在会后立刻推动落地的团队负责人。

需求：让会议决议在会议结束时就已经有人负责、有截止时间、可被追踪。

洞察：行动项被遗漏有三个结构性原因——记录系统与执行系统分离、缺少负责人、没有自动提醒机制[7]。行业数据也印证了这一点：83% 的职场人曾因人工记录疏漏而在会后找不到任务负责人，42% 的会议行动项会被完全遗忘[2]；整体行动项未完成率约为 44%[9]。真正的断点不在「AI 能不能抽出待办」，而在抽出来之后没有人确认、也没有回流到执行系统。

6.12 我方产品五层模型自评（对标 3 款竞品）

战略层
  • 竞品分别绑死「生态 / 个人 / 英文市场」；我方定位中文会议密集团队的「结论可信 + 任务可追」决策助手，避开通义听悟的个人素材场景与飞书的生态锁定
  • 商业化对齐第二节差异化壁垒：免费基础版（转写 + 纪要）／团队全功能（决议追踪 + 协作打通）／企业私有化——价格带落在妙记个人版与 Otter Business 之间
范围层
  • 转写与纪要（R1 / R2）按行业基线补齐即可，不追求功能数量对齐通义听悟的「整理全家桶」
  • 把范围层的主要增量放在 R3（待办识别 + 多工具同步）与 R4（跨会议追问）——恰好是走查中三款竞品得 △ / ✗ 的环节
结构层
  • 飞书证明了「数据全通」的价值（结构层 5 分），但其封闭性留出跨生态空位；我方以开放适配层承接多生态团队的纪要 → 任务 → 状态回写闭环
  • R4 的「结论级检索」（而非文档级 / 词级）在结构层表现为：决议、待办、议题作为一等数据对象入库，而非塞进一份长文档
框架层

  • 三家竞品均无待办进度的一级视图，这是交互框架层最大的空白点
表现层
  • 结构化结论视图（决议 / 待办 / 讨论分栏呈现）+ 待办进度可视化——五层走查确认三款竞品均未提供
  • 中文优先的排版与热词纠错反馈（H2 / H4），把「可信」做成看得见的设计语言

6.13 竞品分析总结与复盘（核心结论）

  1. 市场格局结论：三款竞品分踞「生态型 / 工具型 / 海外型」三个生态位，功能覆盖度总分接近（21 / 17 / 20），但结构层的「纪要 → 外部任务 → 状态回写」闭环三款均未打通（表 14 走查 T3），中文市场的「跨生态决议落地」是真实空白。
  2. 三款竞品各自优缺点：
    • 飞书妙记：优势 = 生态内数据全通、开完会即有纪要；短板 = 出生态即失效、免费额度紧、决议抽取仍需人工校对[10]
    • 通义听悟：优势 = 中文转写与整理能力、多形态输出；短板 = 无会议集成、待办只进不出、团队协作弱
    • Otter.ai：优势 = 自动化程度最高、行动项指派与 CRM 集成；短板 = 中文支持弱、免费墙高、通用任务工具回写有限
  3. 定性 × 定量交叉验证：定量侧（表 11–13）显示三家付费墙都卡在「额度」而功能总分接近；定性侧（表 14 与用户声音）显示真正的不满集中在「闭环断」。两者共同指向同一结论——下一代产品的竞争不在「转写多准」，而在「结论能不能落地」，与 Kano 判定（R2 / R3 期望属性为满意度杠杆）完全一致。
  4. 我方差异化壁垒（匹配 KANO 优先级）：
    • P0 底线（R1）：热词注入 + 结论可溯源，把「不敢信的转写」做成「可验证的结论」，补齐必备属性的行业及格线
    • P0 杠杆（R2 / R3）：四段式结构化纪要 + 待办确认制 + 跨工具状态回写，占据三家竞品全部 △ / ✗ 的空白区
    • P1 亮点（R4）：结论级跨会议追问，作为口碑与传播卖点，不进 MVP 抢资源
    • P2 降级（R5）：仅保留轻量纪要翻译，不与妙记 19 语互译[3]正面竞争
  5. 迭代落地策略：MVP 按 5.5 节节奏交付 H1 + H2 + M1 + M2（含 M3）；M6 多工具适配层优先接通飞书任务与钉钉待办（覆盖国内两个最大生态），第二步再接 Jira / Notion；R4 在 MVP 稳定后 4–6 周内上线。
  6. 长期风险预判：飞书妙记大概率继续深化生态内 AI（问答 / Agent），但跨生态开放不符合字节利益；Otter 若本地化中文市场将直接冲击，需在 12 个月窗口期内以「跨生态决议闭环 + 结论级检索」建立数据壁垒（团队词库与决议库随使用加深而复用成本上升），形成先发护城河。
